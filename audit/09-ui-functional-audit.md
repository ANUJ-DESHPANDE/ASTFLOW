# 09 · UI functional audit (every reachable control)

Method: `audit/tools/ui-crawl.audit.ts` (Playwright + axe) visits 11 UI states at 1440 px and 5 states each at 768 px
and 390 px (21 state × viewport combinations). In each it inventories every visible interactive element (buttons,
links, inputs, selects, textareas, summaries, checkboxes, graph nodes and edges), then — from a fresh load of that
state — interacts with each control once (click / select the next option / fill / toggle) and records the visible
effect (DOM/URL/selection/editor/viewport signature), console and page errors, failed network requests, and axe
results. "Before" = start of the audit; "After" = final build (`537233e` + companion heading fix `89bb5da` verified
separately). The final crawl also opens collapsed `<details>` and scrolls a control into view first, as a user would,
and records which element covers a control's centre when it cannot be clicked.

Raw data: `evidence/ui-crawl-before.json`, `evidence/ui-crawl.json`, screenshots in `evidence/ui-crawl/`;
summary generated by `audit/tools/summarize_crawl.py` (`evidence/ui-crawl-summary.md`).

## The 9 remaining "Error" rows (all explained)

| Rows | What | Why it is not a product defect |
|---|---|---|
| 6 | `textbox ""` fill timeout, covered by a `DIV`/`SPAN` | Monaco's internal input inside a **read-only** editor (it has an accessible label; the crawler reads names differently). Not a user control. |
| 3 | tablet/phone: tab or tab-close button covered by `companion` | After asking a question on a narrow screen the companion **drawer** is open over the workspace by design; choosing a result or pressing Escape closes it (tested in `journeys`/`studio`). |

## Source-code vs runtime inventory

42 `aria-label`s in the current JSX. All interactive ones were reached at runtime. Not reached as *controls*:
landmark/region labels (`Workspace views`, `Workspace tools`, `Code companion`, `Open source files`,
`Repository files`, `Source viewer`, `Source comparison`, `Source-backed call graph`) — containers, not controls — and
`Dismiss error`, which exists only while an error is shown (exercised by `audit.spec.ts` with injected failures). No
unreachable (dead) control was found.
